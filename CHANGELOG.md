# Журнал изменений

Все заметные изменения проекта описываются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
В репозитории нет git-тегов, поэтому дата версии — дата последнего коммита,
вошедшего в неё; значение `version` в `pyproject.toml` (0.1.0) не менялось.

## [1.1] — 2026-10-22

Аудит `known_hosts` (эпик #1787).

### Добавлено
- Безопасное чтение и разбор `known_hosts` (#1794, 2026-10-17).
- Правила KHS001–KHS006, отчёты по ним и маскировка в отчёте (#1795, 2026-10-18).
- Маскировка записей host/port из `known_hosts` в отчёте (#1868, 2026-10-19).

### Изменено
- Чтение файлов больше не подвержено TOCTOU по каталогам-предкам: открытие
  выполняется пошагово по компонентам пути с `O_NOFOLLOW` (#1802, 2026-10-22).

### Тесты
- Дополнены тесты после #1795: откат `os.stat`, точные счётчики (#1833, 2026-10-18).
- Защита от чтения приватных файлов покрывает проверку производительности (#1836, 2026-10-18).
- Тесты отказа в доступе работают и под root (#1860, 2026-10-19).

## [1.0] — 2026-09-29

Базовая версия: только чтение, без изменения ключей и конфигурации.
Первый коммит каркаса — 2026-09-25 (#1376).

### Добавлено
- Команда `scan`: опции, `--redact-output`, коды выхода (#1392, 2026-09-28).
- Команда `explain <finding-id>` (#1394, 2026-09-28).
- Команда `rotation-plan <fingerprint>` (#1393, 2026-09-28).
- Обнаружение `.pub`, отпечатки SHA256, разбор `ssh_config`, `Include`/`Match`,
  разрешение `IdentityFile`, состояние агента, реестр ключей GitHub через `gh`
  (только чтение).
- Правила CFG, ID, LAB, AGT, ALG, REG; JSON-отчёт со схемой 1.0,
  терминальный и Markdown-отчёты.
- Бюджет производительности скана (#1451) и статические границы
  безопасности SEC-004/SEC-006 (#1450).
